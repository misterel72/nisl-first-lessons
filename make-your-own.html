BUILD IT YOURSELF

Make your own interactive lesson

The quickest way to get exactly the activity you want is to describe it clearly and let AI build it. You can do this in Gemini Canvas or Canva Code. No traditional coding required.

✨ Gemini Canvas

Use Gemini when you want to build the app, preview it immediately and keep refining it through conversation.

  1. Open Gemini.
  2. Choose Canvas.
  3. Paste the prompt below and replace the bracketed sections.
  4. Let Gemini build the interactive app.
  5. Open the preview and test every button.
  6. Tell Gemini what to improve in normal language. You do not need to edit the code yourself.

🎨 Canva Code

Canva Code is wonderfully quick when you want the finished activity inside a Canva presentation or published as a webpage.

  1. Open Canva AI.
  2. Select Code.
  3. Paste the prompt below.
  4. Let Canva create the interactive activity.
  5. Select Add to a design.
  6. Choose Presentation and it is ready to use.
  7. If you want a standalone link, publish the design as a webpage.

Copy this prompt into Gemini Canvas or Canva Code

Create a polished interactive classroom activity for a teacher to use live with students. TOPIC OR ACTIVITY: [Describe what you want students to do. For example: an icebreaker about learning preferences, a vocabulary game, a maths challenge, a revision quiz, a debate starter, or a team problem-solving activity.] AGE: [Year group / age] TIME: [How many minutes?] PURPOSE: [What should students learn, practise, discuss or reveal about themselves as learners?] BUILD REQUIREMENTS: - Make it work well on a classroom screen or interactive whiteboard. - Use large, readable text and clear buttons. - Keep instructions short and student-friendly. - Make it visually engaging but not cluttered or childish. - Do not require student logins. - Do not collect personal data. - Include ALL of the content needed to run the activity: prompts, statements, questions, examples, scenarios, clues and answers where appropriate. - Never tell the teacher to “add some questions”, “use more examples” or “repeat with other statements” without providing those actual questions, examples or statements. - Include enough content for the full lesson time. - Include a reset, next round or new question button where useful. - Use British English. - Make the activity easy for a teacher to use immediately without preparing extra resources. PEDAGOGY: - Encourage participation, thinking, discussion or collaboration rather than passive clicking. - Avoid forcing students to share sensitive or highly personal information. - Where useful, finish with a short reflection or exit question. QUALITY CHECK: Before finishing, test the experience as if you were a teacher using it live with 25–30 students. Fix any missing instructions, dead ends or content gaps before showing me the final version.
The important bit: tell the AI to supply the actual classroom content. A beautiful app that says “now ask five questions” is not a finished teaching resource.

Then refine it by talking to the AI

Do not start again because the first version is imperfect. Tell it exactly what is wrong.

  • “The instructions are too wordy. Make them readable from the back of the room.”
  • “Add 15 ready-to-use statements. Do not make the teacher invent them.”
  • “Make this appropriate for Year 4 without making it babyish.”
  • “Add a 60-second discussion timer.”
  • “Make the question text much larger for projection.”
  • “Add a new-round button so I can run this several times.”
  • “Check the whole activity and make sure I can teach it tomorrow without creating anything else.”

Five checks before you use it

  1. Can students read it from the back of the room?
  2. Has it supplied every question, statement, example or scenario you need?
  3. Does every button work and is there a way to reset or continue?
  4. Is it appropriate for the age group and safe for students?
  5. Does it create useful learning, discussion or insight rather than just looking clever?
